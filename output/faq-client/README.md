# Spark client FAQ pack (Liquid Death)

Desktop shots from **https://client.igniteproductions.co** with the **Liquid Death** tenant as the visual exemplar. No mobile. No admin chrome as the hero.

## How to use

1. Open `CLAUDE-DESIGN-PROMPT.md` and copy everything **below** the first `---` into Claude Design.
2. Attach these PNGs (in this order is fine):

| File | What it is |
| --- | --- |
| `01-login.png` | Client login (password + magic link). Fresh session — not logged in. |
| `02-client-dashboard.png` | LD client dashboard (CLIENT VIEW). |
| `03-my-recaps.png` | **My Recaps** — defaults to **Approved**, 30 days. |
| `04-recap-document.png` | Approved recap in the dark shell: white doc, Spark logo, Download PDF / Share. |
| `04b-recap-document-sheet.png` | The white recap document itself (photos, KPIs, sign-off). |
| `05-approvals.png` | **Approvals** — Requests vs Recaps; Approve / Decline. |
| `06-account-map.png` | Account Map (pins + list + schedule). |
| `07-reports.png` | Reports (“The numbers.”). |
| `08-insights.png` | Insights (LD chrome; widgets may still be settling). |
| `09-spark-form.png` | Public **Liquid Death BA Request Form** (`/spark-form/ighn-liquid-death`). |
| `10-ba-checkin-ld.png` | **Field only** — BA check-in `LD-TNBJ8K`. Not a client FAQ hero. |

3. Do **not** attach admin screenshots. If a shot still shows an Admin / Client toggle, that is staff-only — the prompt tells Claude Design to ignore it.

## Login

Login did **not** block the pack. Authenticated pages used an existing client-host session switched to Liquid Death + Client view. `01-login.png` was captured in a separate logged-out context.
